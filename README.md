# Portfolio - Josué Luque

Portfolio personal: presenta mi experiencia laboral, proyectos, perfil y tecnologías.
Bilingüe (ES/EN), con tema claro/oscuro, diseño responsive y foco en rendimiento y accesibilidad.

## Tecnologías

- **Astro** - framework base; genera el sitio estático y los componentes `.astro`.
- **Tailwind CSS** - estilos utilitarios y diseño responsive/mobile-first.
- **TypeScript** - tipado de los datos (perfil, experiencia, proyectos) e i18n.
- **i18n (es/en)** - ruteo por idioma y diccionario de textos de interfaz.
- **Vercel** - hosting y despliegue continuo.

## Design System

Paleta de color, tipografía Onest y escala tipográfica del portafolio.
